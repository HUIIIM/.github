# vertciti 美学标准 v1.0

> **一句话：证据的美学。** 黑白编辑版式承载内容，橙色只负责"指向"，黄色只负责"注意"，
> 每个数字都带出处和日期。看起来像一份可以被审计的年报，而不是一个后台模板。

本标准从生产官网 [vertciti.com](https://vertciti.com)（官网 v4/v6）逐屏提取，适用于
**所有**对外界面：官网、产品 Web 应用、仪表盘、报告、README 截图。token 见
[`tokens.json`](tokens.json)，组件见 [`src/base.css`](src/base.css)，接入见 [`README.md`](README.md)。

对标的行业标杆（取其长处，不抄其皮）：BlackRock corporate（编辑版式与信息层级）、
GOV.UK Design System（克制、可访问、文案即设计）、IBM Carbon（产品界面网格与密度）、
Stripe / Linear（细节完成度与状态设计）。

---

## 1. 七条原则

1. **证据优先。** 数字必须带"来源 · 数据截至 YYYY-MM-DD"；状态必须用诚实三档
   （■ 已验证 / ■ 建设中 / ■ 计划中）。界面上不出现无法复核的数字。
2. **编辑版式，不是控件堆叠。** 每一屏先有标题层级（eyebrow → display → lede），再有控件。
   后台模板式的"灰底 + 白卡 + 一堆输入框"是反例。
3. **黑白为骨，橙色指向，黄色注意。** 大面积只用黑、白、`#F3F3F3`；橙色只出现在：
   当前项下划线、链接箭头、焦点环、进度条、数据条；黄色只出现在：强调卡片、几何装饰、
   跳转链接、警示徽章。一屏内彩色面积 ≤ 10%。
4. **直角与粗线。** 圆角为 0。结构线有三档：1px `--line`（分隔）、2px `--strong`（控件边框/按钮）、
   4px `--strong`（卡片顶线、页脚顶线、强调区块）。
5. **字重即层级。** 800 = 标题与按钮，700 = 标签与导航，400 = 正文，300 = 大数字。
   不用颜色区分层级，用字重和字号。
6. **留白是预算，不是剩余。** 区块间距 `--sec`（64–104px），组件内 24px，控件间 16px，
   全部落在 8px 网格上。
7. **动效只做功能。** 只有：滚动进度条、卡片悬浮上移 2px、展开/收起、骨架屏。
   全部 ≤ 250ms，`prefers-reduced-motion` 下全部关闭。不做数字滚动、不做入场表演。

## 3. 产品应用壳（App Shell）

所有 vertciti Web 产品共用同一套外壳，让用户在产品之间切换时感觉是"同一家公司"：

```
┌──────────────────────────────────────────────────────────────┐
│ vertciti · <产品名>                 ■ 状态   中/EN          │  ← 公司条 40px，黑底白字
├──────────────────────────────────────────────────────────────┤
│ vertciti.  <产品名>   工作台  历史  密钥  定价     [主操作] │  ← 产品头 72px，白底
│                       ━━━━                                   │     当前项 3px 橙色下划线
├──────────────────────────────────────────────────────────────┤
│ 🔔 公告/状态条（#F3F3F3，可关闭）                             │  ← 可选
├──────────────────────────────────────────────────────────────┤
│ EYEBROW                                                      │
│ 页标题 H1                                                     │  ← 页头：eyebrow + H1 + lede
│ 导语 lede                                                     │
│                                                              │
│ 内容（编辑版式：主列 8/12 + 侧栏 4/12，或整列）               │
├━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━┤  ← 4px 黑线
│ vertciti.  产品版本 · 诚实边界图例 · 回官网                   │  ← 应用页脚
└──────────────────────────────────────────────────────────────┘
```

- **导航当前项**：3px 橙色下划线 + 黑字。**不用**黑底胶囊、不用色块高亮。
- **状态**（后端在线/降级/离线）放在公司条右侧：8px 方形色点 + 文字。不用整条彩色横幅。
  需要强提示时用公告条（灰底 + 图标 + 粗体链接）。
- **主操作**：产品头右侧唯一一个黑色实心按钮。一屏只有一个主按钮。
- **移动端**：公司条保留；导航变为横向可滚动标签条，任何标签不得折行。

## 4. 组件规范

所有组件以 `dna-` 前缀实现于 `src/base.css`，Tailwind 项目也直接使用这些类。

| 组件 | 规格 | 反例（禁止） |
|---|---|---|
| 主按钮 `.dna-btn` | 黑底白字，2px 黑边，高 52px（紧凑 44px），800 字重；悬停反白 | 渐变、圆角、阴影按钮 |
| 次按钮 `.dna-btn--secondary` | 透明底 2px 黑边 | 灰底按钮 |
| 文字链接 `.dna-arrow` | 800 字重 + 橙色 → 箭头，悬停箭头右移 4px | 蓝色下划线链接 |
| 卡片 `.dna-card` | 白底，4px 黑色顶线，24–28px 内边距；变体 `--ink`（黑）`--accent`（黄） | 圆角卡片阵、四周阴影 |
| 输入框 `.dna-input` | 高 48px，1px `--fg-3` 边，聚焦 3px 橙色焦点环；标签在上方，700 字重 | 占位符代替标签、灰底输入框 |
| 分段选择 `.dna-seg` | 方形相连按钮，选中黑底白字 | 胶囊开关 |
| 标签页 `.dna-tabs` | 底部 1px 线，当前项 3px 橙色下划线 | 黑底胶囊标签 |
| 状态点 `.dna-dot` | 8px 方块：`--ok` 已验证 / `--warn` 建设中 / `--fg-3` 计划中 | emoji 圆点做状态灯 |
| 数据卡 `.dna-stat` | 大数字 300 字重 + 粗体标签 + 出处行 + 橙色数据条 | 无出处数字、数字滚动动画 |
| 提示 `.dna-alert` | 软灰底 + 4px 左边色条 + 粗体标题 | 整块彩色底 |
| 表格 | 表头 2px 黑底线，行 1px 线，数字右对齐等宽 | 斑马纹彩色表 |
| 空状态 | eyebrow + 一句话 + 一个下一步按钮 | 插画占满屏 |
| 加载 | 灰色骨架条（`#F3F3F3`），不转圈超过 1 秒 | 全屏转圈 |
| 代码块 | 黑底 `#000` + 白字 `--mono`，0 圆角 | 主题花哨的语法高亮底色 |

## 5. 几何装饰

官网的记忆点之一是黄/橙几何：L 形黄框、圆环、三角、方块。规则：

- 只用在**强调卡片、页头插画位、空状态**，每屏最多一处。
- 只用 `--orange`、`--yellow`、`--strong`；描边 12–24px，不加渐变、不加阴影。
- 必须是 `aria-hidden` 的纯装饰 SVG。

## 6. 文案即设计

- 中文为主，英文对照；按钮是动词（"获取报价"不是"提交"）。
- 不说"即将上线""业界领先"。说清楚现在能做什么、不能做什么。
- 错误信息 = 发生了什么 + 你能做什么："连不上服务器。检查网络后重试。"
- 品牌名永远小写 `vertciti`，句号形式 `vertciti.` 只用于标识。

## 7. 质量门禁（发布前必须全部通过）

| 门禁 | 标准 | 工具 |
|---|---|---|
| 视觉 | 390 / 768 / 1440 三档截图人工过审，无折行、无溢出、无重叠 | Playwright 截图 |
| 无障碍 | axe-core 0 个 serious/critical；键盘可走完主流程；焦点环可见 | axe / 手测 |
| 对比度 | 全部文字 ≥ 4.5:1，大字与 UI ≥ 3:1 | `build.py --check` |
| 触控 | 可点击目标 ≥ 44×44px | website-qa-gates G3 |
| 性能 | Lighthouse 性能 ≥ 90、可访问性 ≥ 95、最佳实践 ≥ 95；CLS < 0.1 | Lighthouse CI |
| 一致性 | 无 DNA 外颜色、无圆角、无外部字体请求 | `dna-drift` + grep |
| 诚实 | 每个数字有出处；状态用三档；截图为真实运行 | 人工审 |

不通过任何一项 = 不发布。
