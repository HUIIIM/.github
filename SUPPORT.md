# Support

- **How do I use this?** → Open an issue on the relevant repository.
  Public Q&A helps everyone — private email for technical questions
  is not monitored.
- **I found a security issue** → See [SECURITY.md](SECURITY.md).
  Never open a public issue for it.
- **I want to contribute** → See [CONTRIBUTING.md](CONTRIBUTING.md).
- **Anything else** → Contact links on [vertciti.com](https://vertciti.com).

This file cascades as the default for every repository under
[@HUIIIM](https://github.com/HUIIIM) that doesn't define its own
support channels.
