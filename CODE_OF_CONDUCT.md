# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be kind, be honest, no harassment, no hate. Healthy disagreement
about technical decisions is welcome; personal attacks are not.

## Enforcement

Violations can be reported privately — use the affected repo's
**private vulnerability reporting** channel, or the contact links on
[vertciti.com](https://vertciti.com). Every report is reviewed by the
maintainer; confirmed violations lead to warnings, then bans.

This file is intentionally a reference, not a copy: the Covenant text
lives upstream so it never goes stale here. It cascades as the default
for every repository under [@HUIIIM](https://github.com/HUIIIM) that
doesn't define its own code of conduct.
