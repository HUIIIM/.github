# .github

Shared GitHub configuration for [@HUIIIM](https://github.com/HUIIIM) —
Jiahui Miao's open-source work at [vertciti](https://vertciti.com).

This is a personal account, not an organization. Files here cascade as
defaults to every repository under [@HUIIIM](https://github.com/HUIIIM)
that doesn't define its own.

| Path | What it is |
|---|---|
| [`profile/README.md`](profile/README.md) | The vertciti company profile card |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to contribute — find a task, fork, PR, review |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant v2.1 (referenced, not copied) |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability — private, never a public issue |
| [`SUPPORT.md`](SUPPORT.md) | Where to ask for help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Bug report / feature request forms |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | What every PR must answer |

Nothing secret ever lives in this repo — community files must stay public
to cascade, so credentials and private notes stay out.
